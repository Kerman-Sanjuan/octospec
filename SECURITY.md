# Security Policy

## Supported versions

The latest release is supported. Reinstall with `curl | sh`, or run `octospec update`.

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting on this repository: open the **Security** tab and choose **Report a vulnerability**. Do not open a public issue for a vulnerability.

Please include the version (`octospec version`), your OS and architecture, and the steps to reproduce it.

You will get an acknowledgement, and a fix or a plan, as fast as the maintainer can.

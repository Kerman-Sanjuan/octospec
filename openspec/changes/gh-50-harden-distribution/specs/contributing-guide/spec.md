## ADDED Requirements

### Requirement: A contributing guide
The repository SHALL have a `CONTRIBUTING.md` for humans.

#### Scenario: A newcomer finds the guide
- **WHEN** a newcomer looks for how to contribute
- **THEN** `CONTRIBUTING.md` explains how.

### Requirement: The guide teaches the workflow
`CONTRIBUTING.md` SHALL explain the loop, the branch naming, how to run the tests, and how to cut a release.

#### Scenario: Send a change
- **WHEN** a contributor follows the guide
- **THEN** they can run the loop, name a branch, run the tests, and cut a release.

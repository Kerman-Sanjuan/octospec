# Issue #34: Consumer docs

https://github.com/Kerman-Sanjuan/octospec/issues/34

## User story

As someone adopting octospec, I want documentation to install it and run the loop.

## Context / problem

The README is written for the project. There is no getting started, no command reference for consumers, and no troubleshooting.

## Requirements

- A getting started guide, a command reference, and a troubleshooting section SHALL exist and be linked from the README.

## Success criteria

- A new user can install octospec and run the loop from the docs alone.

## Out of scope

- A hosted docs site.

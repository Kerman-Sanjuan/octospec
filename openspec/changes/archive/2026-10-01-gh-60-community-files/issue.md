# Issue #60: Add SECURITY.md, CODE_OF_CONDUCT.md, and issue/PR templates

https://github.com/Kerman-Sanjuan/octospec/issues/60

## User story

As a visitor, I want the standard community files, so I know how to behave, how to report a vulnerability, and how to send a change.

## Context / problem

The repository is public but lacks `SECURITY.md`, `CODE_OF_CONDUCT.md`, a pull request template, and `.github/ISSUE_TEMPLATE/config.yml`.

## Requirements

- The repository SHALL have a `SECURITY.md` with a reporting channel.
- It SHALL have a `CODE_OF_CONDUCT.md` that adopts the Contributor Covenant.
- It SHALL have a pull request template.
- It SHALL have an `ISSUE_TEMPLATE/config.yml` that links the security policy and the question channel.

## Success criteria

- GitHub surfaces the security policy and the code of conduct on the repository.
- A new pull request starts from the template.

## Out of scope

- A contributor license agreement.

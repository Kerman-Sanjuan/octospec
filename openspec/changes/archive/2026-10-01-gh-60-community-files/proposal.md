## Why

The repository is public but lacks the standard community files. GitHub expects a security policy and a code of conduct, and a pull request template keeps contributions consistent.

## What Changes

- Add `SECURITY.md` with a private reporting channel.
- Add `CODE_OF_CONDUCT.md`, adopting the Contributor Covenant.
- Add a pull request template.
- Add `.github/ISSUE_TEMPLATE/config.yml` that links the security policy.
- Link the code of conduct from `CONTRIBUTING.md`.

## Capabilities

### New Capabilities
- `community-files`: the public-facing community files, the security policy, the code of conduct, and the issue and pull request templates.

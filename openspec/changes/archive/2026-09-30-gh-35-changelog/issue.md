# Issue #35: CHANGELOG and release process

https://github.com/Kerman-Sanjuan/octospec/issues/35

## User story

As a maintainer, I want a versioned changelog and a stated release step.

## Context / problem

The goreleaser config exists, but the human release process and the changelog do not.

## Requirements

- A `CHANGELOG.md` SHALL be kept, grouped by impact.
- The release steps SHALL be documented, and tags SHALL follow semantic versioning.

## Success criteria

- Each release has a changelog entry and a documented, repeatable process.

## Out of scope

- Release automation beyond tagging.

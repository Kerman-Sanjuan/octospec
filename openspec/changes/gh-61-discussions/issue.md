# Issue #61: Enable GitHub Discussions or fix the CONTRIBUTING reference

https://github.com/Kerman-Sanjuan/octospec/issues/61

## User story

As a contributor, I want the question channel named in `CONTRIBUTING.md` to exist, so I can ask a question where the docs tell me to.

## Context / problem

`CONTRIBUTING.md` tells people to use GitHub Discussions, but Discussions are disabled on the repository, so the guidance points at nothing.

## Requirements

- The repository SHALL either enable GitHub Discussions, or `CONTRIBUTING.md` SHALL point to a channel that exists.

## Success criteria

- Following `CONTRIBUTING.md` leads to a real place to ask a question.

## Out of scope

- A chat server.

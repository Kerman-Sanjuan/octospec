## Why

`CONTRIBUTING.md` points people at GitHub Discussions, but the repository has Discussions disabled, so the guidance leads nowhere. A public tool needs a real question channel.

## What Changes

- Enable GitHub Discussions on the repository.
- Link Discussions from the issue chooser config.
- Keep `CONTRIBUTING.md` pointing at Discussions.

### New Capabilities
<!-- None. -->

### Modified Capabilities
- `community-files`: the issue chooser links the question channel, and the repository provides it.
